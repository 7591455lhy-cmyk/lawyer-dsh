## 摸鱼工作站 0.80

首个公开发行版。右侧一个功能栏，把「合同审核 / 案件分析 / 文书生成」变成
**填表即发起**的任务：填完表单，它自己新建会话、切到律师 preset、按中国法
工作流把成果写到你的工作区。

### 系统要求

- Windows 10 1803 及以上、x64
- 磁盘：安装后约 500MB，建议预留 1GB
- 网络：需联网
- 自备 DeepSeek API Key（[申请](https://platform.deepseek.com/api_keys)）；
  元典 Key（法规 / 案例检索）可选

### 本次更新

**新增**

- 三个开箱任务：合同审核（立场 / 严格程度 / 材料）、案件分析、文书生成
  （民事起诉状、答辩状、代理词、法律意见书）。
- 自定义功能入口：字段、模板、附加技能与 agent preset 可配。
- 每次任务独立新建会话，任务之间零上下文污染。
- 实务画像三层：快速表单 / 完整问卷 / 原文直编；完整问卷按**执业律师 · 公司法务**
  分叉成 4 套问题链（商事、诉讼各两套）。
- 首启引导：DeepSeek API Key 与元典检索 Key 都能在界面里配齐。
- 中国法工作流：按 claude-for-legal-ZH 的规范路由领域 adapter、技能与质量门禁。
- 聊天区里的成果文件路径可直接点击打开；无工作区时自动建兜底目录。

**修复**

- 首启引导弹窗被壳的 `inert` 锁死（点不动、跳不过）→ 弹窗改为 portal 到 body。
- 自建界面主按钮「黑字压黑底」不可读 → 主按钮文字改用正确的主题令牌。
- 演示回放的成果路径占位符被反引号包裹时永不替换 → 路径点击无反应。
- `dsh-worktable` 被运行时跳过装配（界面空白 / `client.js` 404）→ 剥除
  `dsh.bundle`。
- 剔除演示数据后留下悬空标识符 → 构建加 `--minify-syntax`。

### 已知问题

- 元典端点握手阶段不校验 Key 归属：「校验通过」不等于 Key 可用，以会话里
  能否检索到条文为准。
- 打包环境没有目录选择器，工作区由主进程预创建兜底目录
  （`<用户目录>\摸鱼工作站-工作区`）。
- 非表单产物（模型在会话里写成的画像）默认停在「原文直编」。
- `pdfkit-py` 是技能市场的第三方技能，不随包分发；未安装时 PDF 相关能力不可用。
- 安装包内的工作台项目为示例数据，可自行替换。

### 安装与首启

1. 下载安装（可选安装目录）。
2. 首次启动按引导填 DeepSeek API Key。
3. 点右侧栏「合同审核」→ 填表 →「开始」。

详见 [`docs/安装-安装包版.md`](../安装-安装包版.md)；高频问题见
[`docs/常见问题.md`](../常见问题.md)。

### 升级

覆盖安装即可。设置、画像与凭据都在用户目录，不会被覆盖。
