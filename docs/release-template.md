## 摸鱼工作站 0.80

一句话：右侧一个功能栏，把合同审核 / 案件分析 / 文书生成变成填表即发起的任务。

### 下载

| 文件 | 大小 | SHA256 | 适用 |
| --- | --- | --- | --- |
| `摸鱼工作站-Setup-0.80.exe` | 175 MB | `<粘贴 certutil 的结果>` | Windows 10 1803+ / x64，普通用户 |

校验：

```powershell
certutil -hashfile 摸鱼工作站-Setup-0.80.exe SHA256
```

> 插件版（不含桌面壳）在 [lawyer-sidebar](https://github.com/7591455lhy-cmyk/lawyer-sidebar) 仓库发布。

### 系统要求

- Windows 10 1803 及以上、x64
- 磁盘：安装后约 500MB，建议预留 1GB
- 网络：需联网
- 自备 DeepSeek API Key；元典 Key（法规 / 案例检索）可选

### 已知问题

- 元典端点握手不校验 Key 归属，「校验通过」不等于 Key 可用。
- 打包环境没有目录选择器，工作区由主进程预创建兜底目录。
- `pdfkit-py` 为技能市场第三方技能，不随包分发；未安装时 PDF 能力不可用。

### 安装与首启

1. 下载 exe 并安装（可选安装目录）。
2. 首次启动按引导填 DeepSeek API Key；元典 Key 可在侧栏底部配置。
3. 点右侧栏「合同审核」→ 填表 →「开始」。

详见 [`安装-安装包版.md`](../blob/master/docs/安装-安装包版.md)。

### 升级

覆盖安装即可；设置、画像与凭据都在用户目录，不会被覆盖。
