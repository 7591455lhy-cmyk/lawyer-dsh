# 安装与使用（安装包版）

本文件面向**直接使用**的人：下载、安装、首启、日常使用、升级与卸载。
开发者请看 [`构建与出包.md`](./构建与出包.md)。

## 一、下载

到本仓库 Releases 页面，下载最新版本的 `摸鱼工作站-Setup-<版本>.exe`
（约 175MB）。Release 说明里附了 SHA256，可用下面的命令核对：

```powershell
certutil -hashfile 摸鱼工作站-Setup-0.80.exe SHA256
```

与 Release 说明里的值逐字符一致即可安装。

## 二、安装

1. 双击安装包，按向导进行（可选安装目录，默认装在
   `%LOCALAPPDATA%\Programs\摸鱼工作站`）。
2. 安装完成后可勾选立即运行。

首次启动会做几件事，各需一点时间（首次约 1～2 分钟）：

- 把随包的 dsh 运行时、web profile、lawyer agent preset、中国法语料部署到
  用户目录（版本号变化时才重新部署，之后启动很快）；
- 预创建兜底工作区目录（`<用户目录>\摸鱼工作站-工作区`），避免「点了任务没反应」；
- 拉起本地服务并打开界面。

## 三、首次使用：把两个 Key 配齐

### 1) DeepSeek API Key（必填）

首启会先弹引导，讲清「注册 → 创建 Key → 充值」三步并给出可点外链（跳转系统
浏览器）。点「去填写」后交给官方的输入框粘贴 Key。

- 没有 Key：引导里有直达链接（[注册 / 登录](https://platform.deepseek.com/sign_in)、
  [创建 API Key](https://platform.deepseek.com/api_keys)、[充值](https://platform.deepseek.com/top_up)）。
- 关掉引导也没关系：之后到 **Settings → Models** 里同样能填，输入框下方也
  附了这几个链接。

### 2) 元典 Key（可选，用于法规 / 案例检索）

点右侧栏任一任务入口时，若检测到没有配置元典 Key，会弹引导：三步说明 +
粘贴保存 + 立即校验 + 平台外链。也可以随时在侧栏底部的「实务画像」分节里
找到配置入口。

> 注意：元典端点握手阶段**不校验 Key 归属**——任意非空 Key 都会返回「已连通」。
> 校验只能证伪不能证实，Key 是否真正可用以会话里实际能检索到法条为准。

不配置也能正常使用：合同审核按技能内置降级指引继续，法条靠模型记忆，只是
不能保证条文与案号的准确性。

## 四、日常使用

- **发任务**：右侧栏点「合同审核 / 案件分析 / 文书生成」→ 填表 →「开始」。
  每次任务都会新建独立会话，任务之间互不干扰。
- **加自己的任务**：侧栏底部「添加自定义功能」，配字段、模板与技能。
- **实务画像**：侧栏底部「实务画像」→ 快速表单（高频字段）或完整问卷
  （按执业律师 / 公司法务分叉，商事与诉讼共 4 套）。留空即按通用标准处理。
- **打开成果文件**：聊天区里的文件路径可直接点击，用系统默认程序打开。
- **切换工作区**：dsh 原生的工作区选择器；打包环境没有目录浏览能力，
  默认使用上述兜底工作区。

## 五、数据都在哪

| 内容 | 路径 |
| --- | --- |
| dsh 用户目录（`DSH_HOME`） | `%APPDATA%\lawyer-workbench\dsh-home` |
| 日志 | `%APPDATA%\lawyer-workbench\logs\dsh-web.log` |
| 工作台项目数据 | `%APPDATA%\lawyer-workbench\dsh-worktable\data` |
| 中国法语料 | `%APPDATA%\lawyer-workbench\legal-zh` |
| 元典 Key | `%APPDATA%\lawyer-workbench\dsh-home\lawyer-secrets.json`（明文，靠系统账户权限保护） |
| 兜底工作区 | `<用户目录>\摸鱼工作站-工作区` |

调试模式（从源码跑 `debug-web.cmd`）则使用 `%USERPROFILE%\.dsh`。

## 六、升级

直接覆盖安装新版本即可。安装包内的 `VERSION` 变化时会重新部署 profile 与
preset；你自己的设置、画像与凭据都在用户目录里，不会被覆盖。

## 七、卸载

在「设置 → 应用」里卸载。**卸载不会删除用户数据**（安装脚本刻意保留），需要
彻底清理时手动删除：

- `%APPDATA%\lawyer-workbench`
- `<用户目录>\摸鱼工作站-工作区`（你的工作区文件，删前请确认）
- 安装目录（默认 `%LOCALAPPDATA%\Programs\摸鱼工作站`）

## 八、遇到问题

先看 [`常见问题.md`](./常见问题.md)。仍不能解决，请带着日志
（`%APPDATA%\lawyer-workbench\logs\dsh-web.log`）提 Issue；贴日志前请脱敏，
**不要贴 API Key**。
