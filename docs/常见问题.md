# 常见问题

先确认版本：安装包文件名或侧栏显示即版本号。本文按「现象 → 原因 → 怎么办」组织。

## 启动与安装

**启动就弹「安装不完整，缺少运行时文件：…」**
`assertRuntime` 在启动前校验随包 runtime，缺任何一个都不放行。多半是安装包
下载不完整或被杀毒软件拦下了某个文件。重新下载安装；仍不行就关掉杀软重试，
并把弹窗里的缺失清单附到 Issue。

**首启很慢（一两分钟）**
首次启动要部署 dsh 运行时、web profile、preset 与中国法语料，之后由 `VERSION`
标记跳过，重启就快了。

**第一个引导界面点不动 / 无法跳过**
0.80 已修复：引导弹窗曾被壳的 `inert` 锁死，现改为 `createPortal` 到 body。
若你用的是更早的版本，请升级到 0.80。

**界面上成对按钮有一个是全黑、文字看不清**
0.80 已修复（主按钮文字改用了正确的主题令牌）。旧版本请升级。

## 凭据与模型

**模型不回答 / 一直转圈**
依次检查：① DeepSeek API Key 是否填了（Settings → Models）；② 账户余额；
③ 网络能否访问模型服务。日志在
`%APPDATA%\lawyer-workbench\logs\dsh-web.log`（调试模式是仓库根的
`.dsh-web.log`）。

**法规 / 案例检索没结果**
元典 Key 未配置或无效。侧栏底部「实务画像」分节里有常驻配置入口。
注意：**元典端点握手阶段不校验 Key 归属**，任意非空 Key 都会显示「已连通」，
所以「校验通过」不代表 Key 真的能用——以会话里能否检索到条文为准。
不配置也能跑，只是法条靠模型记忆，准确性不保证。

## 任务与文件

**点了任务入口没反应**
需要至少存在一个工作区。0.80 会自动预创建兜底目录
（`<用户目录>\摸鱼工作站-工作区`）；若创建失败（例如权限受限），请手动在
dsh 里添加工作区。

**上传合同 / 材料失败**
上传走 Host 的 `lawyerFiles` 服务写入工作区（`.lawyer-uploads/`）。检查工作区
是否存在、目录是否可写。浏览器沙箱拿不到拖入文件的真实路径，所以文件必须先
上传进工作区，模型才能读。

**PDF 材料处理不了**
PDF 转换与扫描件转录依赖 `pdfkit-py`，它是技能市场的**第三方技能，不随本
项目分发**。需要请自行从技能市场安装到 `skills/`；不装的话其余功能不受影响，
只是 PDF 相关能力不可用。

**合同审核没有生成修订留痕的审阅稿**
审阅稿由 `docx-tracked-changes` 技能产出。若 Host 没注册到技能（配置里的
`skillsDir` 指向不正确或目录为空），相关能力缺失。调试模式下看启动日志：
缺 `skillsDir` 会打印「律师技能未注册」。

**聊天里的文件路径点了没反应**
只有带常见扩展名（docx/pdf/xlsx/png/txt 等）的绝对路径会被识别为可点击；
被反引号包裹、带 `@` 前缀或引号包裹的路径 0.80 均已支持。若仍无效，检查该
文件是否还在原位置（跨机器回放时路径会变）。

## 实务画像

**画像保存后再打开，内容不对 / 读不到**
画像正文的 canonical 路径是 `<DSH_HOME>/legal-zh/<领域>/CLAUDE.md`，由 Host
统一决定。**打包版的 `DSH_HOME` 是 `%APPDATA%\lawyer-workbench\dsh-home`**，
与调试模式的 `%USERPROFILE%\.dsh` 不是同一处——在调试环境写的画像，打包版
读不到（反之亦然），这是预期行为。

**模型访谈产出的画像，表单里看不到**
非表单产物默认停在 L3「原文直编」，避免被表单覆盖。想让表单接手，先在 L3
里整理成表单能解析的形态。

**完整问卷怎么只有一套问题**
完整问卷按执业身份分叉：商事与诉讼各有「执业律师版 / 公司法务版」共 4 套。
首步「执业身份」里选了什么，后面就走哪一套；改了首步答案会即时切换。

## 界面

**右侧栏不显示**
① 强刷（Ctrl+F5）；② 确认插件已装配（调试模式重跑 `debug-web.cmd`，它会
先 remove 再 add）；③ 安装包版启动时若 runtime 部署失败会弹错，按提示处理。

**左侧工作台区域空白**
`dsh-worktable` 曾因同时声明 `dsh.bundle` 与 `dsh.client` 被运行时跳过装配
（表现为 `/plugins/dsh-worktable/client.js` 404）。0.80 的打包脚本已剥除
`dsh.bundle`，升级即可。

**「⚡ 载入演示数据」按钮不见了**
对外发布的安装包用 `build.ps1 -NoDemo` 构建，刻意不带演示数据。内部演示或
开发时，不带 `-NoDemo` 重新构建即可出现。

## 调试与卸载

**3080 端口被占用**
`debug-web.cmd` 启动前会按端口杀掉旧进程；不要同时开两个调试实例。

**卸载后想彻底清理**
卸载**不删用户数据**（刻意保留）。手动删除：`%APPDATA%\lawyer-workbench`、
`<用户目录>\摸鱼工作站-工作区`（你的工作区文件，删前确认）、安装目录
（默认 `%LOCALAPPDATA%\Programs\摸鱼工作站`）。

**想看更详细的排障记录**
`docs/交接指南.md` 的「已知坑位清单」与 `CODEBUDDY.md`（项目约定与踩坑）
是开发者视角的完整记录。
