# 案件分析报告摘要

**案件**：恒信建材有限公司 诉 华远装饰工程有限公司 买卖合同纠纷（瓷砖采购）｜**我方立场**：被告方｜**全模块分析**

## 一、核心事实（无争议）

- 2024-03-06 签订采购合同：货到**7日内书面质量异议**（逾期视为合格）、**货到验收后30日付款**、逾期按**日万分之五**付违约金。
- 五批供货累计 **876,000 元**（已开票、数量经群确认）；被告已付 **400,000 元**，**欠付 476,000 元**；原告三次催告（09-02/10-15/11-06），2024-11-18 起诉，诉请货款 476,000 元＋违约金 95,200 元。

## 二、争议焦点

| 焦点 | 类型 | 权重 |
|---|---|---|
| 质量异议（空鼓＋第三、四批色差尺寸偏差）能否折价 120,000 元 | 事实＋法律 | 高 |
| 违约金 95,200 元的计算方式与是否过高酌减 | 法律 | 高 |
| 欠付本金 476,000 元 | 事实（争议性低） | 中 |
| 微信群提空鼓是否构成合同项下"书面质量异议" | 法律 | 中 |

## 三、风险评估（被告视角）

| 事项 | 评估 | 等级 |
|---|---|---|
| 本金 476,000 元被支持 | 无实质抗辩，概率约 85%-95% | **高（不利）** |
| 违约金 95,200 元全额支持 | 原告计算明显错误（相当于自 2024-05-02 起算、早于任何应付日），概率＜5% | 低 |
| 违约金酌减 | 正确分段计算仅约 **21,670 元**（日万分之五＝年化 18.25%，为同期 LPR 3.1% 的 5.9 倍），法院大概率酌减至 LPR 基准区间（约 0.5-1.5 万） | 中低（有利） |
| 质量折价抗辩成立 | 第三、四批签收后 85/50 天才书面提出，远超 7 日异议期（《民法典》第 621 条视为合格），无检测依据，概率约 10%-20% | 高（作主防线时） |
| 原告申请财产保全 | 概率较高，可能冻结账户 | 中 |
| 调解前景 | 本金无争议、争点集中，空间较大 | 正面 |

## 四、结论与策略建议

1. **答辩主线**：认可欠付本金（避免恶意拖延定性），全力打违约金——先纠正原告"基数含已付款、起算点错误、未分批计算"（95,200 元 → 正确约 21,670 元），再依《民法典》第 585 条第 2 款请求酌减。
2. **质量抗辩降级为筹码**：异议期已过＋无检测依据，成立概率低；若坚持须先做第三方检测/评估鉴定可行性（费用数万、耗时数月、结论不确定），不建议作主防线，但可用于换取调解折价（3-5 万元）。
3. **调解目标**：本金 476,000 元分期/一次性 ＋ 违约金按 LPR 基准（约 1-2 万元）＋ 诉讼费合理分担，规避保全与鉴定成本。
4. **证据固定优先级**：付款回单 → 微信原始载体（勿删聊天记录）→ 签收单 → 施工记录（证明空鼓系铺贴工艺问题）→ 检测报告。
